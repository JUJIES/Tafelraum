# Designing a worksheet from references

For a new or substantially revised worksheet, choose two or three different examples from the [reference index](README.md). Open the complete pages in a browser and inspect the HTML, CSS and local images together. Reading the source alone does not establish how a page looks. For a small correction, start with the existing worksheet and preserve what already works.

Choose references for particular decisions. The Madeira sheet pairs the title with an illustration and separates numbered instructions from response boxes. The engine diagram ties labelled image details to short answers. Translation Bridge distinguishes a short entry, a draft and a final response. Use only the patterns that suit the learning task.

- **Header.** Give the subject or unit a quiet label, the worksheet a clear title and the task a short introduction. A rule or header area can establish the top of the page. The reading and listening examples often use a serif title; the engine sheets also demonstrate a sans-serif treatment.
- **Assignments.** Give each main task a recognisable visual treatment and enough room to do it. A number, pale background or accent edge can help. Keep follow-up questions smaller. A single overall task does not need an artificial number.
- **Answers.** Size fields for the expected response. Counting grid edges, drafting one sentence and explaining a decision need different amounts of handwriting space. Use the HTML material skill for input, print and state requirements.
- **Page structure.** Choose page count, order and orientation to suit the task. Check the print layout at the intended size. Do not shrink the text or add filler to meet a page count.
- **Footer.** Leave space at the bottom of the text area for a quiet rule and page number. Keep it clear of answer fields.
- **Personal information.** Add name, date or time fields only when requested. A planned lesson duration does not imply the worksheet needs a time field.

Record which references you viewed and which decisions you carried over. Check the new page for reading order, hierarchy, image-to-task correspondence and writing space. Technical validation, visual inspection, actual printing and classroom use are separate checks. Digital simulations and games can use a layout suited to interaction instead of resembling a sheet of paper.

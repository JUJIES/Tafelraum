# Provenance of the worksheet references

The thirteen packages were copied on 30 October 2026 from the JUJIES teaching material package 0.1.65, under `skills/arbeitsblatt-html/assets/vorlagen/`. The selected HTML, local assets and licence texts were compared with the source package. No private lesson archive, plugin runtime or provider connection is required.

The original provenance record (`MATERIALRECHTE.md`, 21 October 2026) identifies the tasks and teaching texts as project material. The reading companion contains no book extracts or illustrations. The listening tasks do not include third-party recordings. ImageGen was used for the film and Madeira illustrations; they are not film stills. The drug harm materials use original text with cited sources and do not reproduce the Lancet chart. Check the currency of historical sources separately.

The project’s [MIT License with Commons Clause 1.0](../../LICENSE) applies to its own work. Preserve the separate terms for these third-party assets:

- **Engine parts.** Wapcaplet/Shizhao, CC BY-SA 4.0. The [asset credit](ottomotor-bauteile-funktionen/assets/LIZENZEN.md) records the image modification and links to the full terms.
- **Four strokes.** Wapcaplet, CC BY-SA 3.0. The [asset credit](ottomotor-vier-takte/assets/LIZENZEN.md) applies to the cropped pictures as well.
- **Translation Bridge icons.** Lucide, ISC. Licence texts are beside the SVGs.
- **Fonts.** The worksheets request system fonts through CSS and do not distribute font files.

Review changes to the reference set and add selected files to `files.json`. The kit is built from these repository files, without automatically synchronising private archives or plugin caches. Preserve attribution when reusing assets. Keep answer keys separate from student materials and presentation clips. A reference’s historical use or print review does not establish that a modified worksheet is ready to teach or print.

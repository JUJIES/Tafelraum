# Historical teaching surface study

The second study combined independent room tools, a public teacher pointer and a transient click pulse. The roomy toolbar handle followed the drag, docked to any side on release and changed orientation. A deliberate click briefly drew quiet rings at the pointer. Contrast, latency, snap thresholds, reach and undo boundaries needed hardware tests.

These mockups were discussion material, not a pixel specification. The original screenshots contained lesson artwork without documented redistribution rights and are not included. See the [teaching surfaces brief](../../02_TEACHING_SURFACES_UI_BRIEF.md).

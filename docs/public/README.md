# Öffentliche Dokumentationsauswahl

Diese geprüften Kurzfassungen werden ausschließlich beim lokalen Quell-Export
nach `public-source.json` an die dort genannten Dokumentpfade kopiert.
Der gemeinsame Arbeitsbaum behält seine vollständigen lokalen Originalprotokolle.

Technische Bereichsverträge, Architekturentscheidungen und UI-Briefe bleiben
Bestandteil des öffentlichen Quellstands. Persönliche Unterrichtsfallarchive und
die detaillierte Installations-/Kontaktprüfhistorie werden nicht mitgegeben.
Absichtlich lokale Material-/Prüfbelege werden im Export als solche bezeichnet.
Fehlende Code-/Anleitungsdateien dürfen dadurch nicht versteckt werden.

Die Dokumentauswahl ändert keine Lizenzen oder Unterrichtsdaten. D-330 ergänzt
die explizite Funktionsauswahl über feste Distributionsadapter; diese ist im
[Vertrag61](../implementation/61_DISTRIBUTION_BOUNDARY.md) beschrieben.
Sein Manifest nennt Ersetzungen und Ausschlüsse. Die Kurzfassungen bestätigen
keine fremden Testergebnisse oder Installation eines neuen Appstands.

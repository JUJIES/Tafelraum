# Teaching Workspace concept package, version 1.4

This directory contains the original German design research from 30 August 2026, when the project was still called Teaching Workspace. It records classroom needs, possible product directions, engine experiments and unresolved questions. For implemented public features, start with the [project README](../../../README.md).

The central idea was to let a teacher arrange material freely, structure it later and deliberately choose what to show. The proposed model distinguished lesson content and activities, optional lesson flow, editable board views and an actual teaching session. Original files would be stored outside the canvas payload. The board engine would sit behind an adapter.

Topics include [product principles](02_PRODUKTPRINZIPIEN_UND_WORKFLOWS.md), [data modelling](04_DOMAENENMODELL_UND_DATEN.md), [touch and materials](05_WHITEBOARD_TOUCH_UND_MATERIALIEN.md), [presentation](06_TAFELREGIE_LIVE_HOLD.md), [architectural decisions](16_ARCHITEKTUR_STACK_UND_CANVAS_ENTSCHEIDUNG.md) and [schema examples](schemas/README.md). Ideas such as remote participation, permanent publication and alternate engines describe the original study. The live public edition uses the local teacher canvas and Room Canvas.

# Transport-Demo

`transport-set.png` ist das versionierte neutrale Demoasset für den Canvas-Seed
und den Clip-Browsertest. Ein frischer Checkout braucht dafür keine Dateien aus
`test-materials/` oder einem Unterrichtsarchiv.

Am 29.10.2026 unabhängig mit dem eingebauten ImageGen-Werkzeug erzeugt, ohne
Referenzbild oder Übernahme aus dem privaten Unterrichtskorpus. PNG, 1536 × 1024.
Es ersetzt die bisherige private Unterrichtskopie als technische Demo; daraus
folgt keine Freigabe des alten Korpus. Für dieses eigene Demo gelten seit D-324
die [Projektbedingungen](../../../../../LICENSE), soweit entsprechende Rechte
bestehen; die [Herkunftsmatrix](../../../../../ASSET_PROVENANCE.md) ordnet es ein.

Die bestehende Datei-ID `tafelraum-transport-set`, PNG-Ladefunktion und Canvasgeometrie
640 × 427 bleiben erhalten. Der bisherige Demo-Sonderpfad lädt diese Datei auch bei alten Demoobjekten
mit derselben Datei-ID erneut. Daher ändert sich dort ebenfalls die Illustration;
regulär importierte Unterrichtsassets mit eigenen Datei-IDs bleiben unverändert.
Es gibt keine Archivmigration.

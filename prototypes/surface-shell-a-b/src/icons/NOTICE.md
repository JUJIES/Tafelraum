# Fluent UI System Icons

The dockable toolbar uses the official Microsoft Fluent UI System Icons package (`@fluentui/svg-icons`). `ColoredPencilIcon.tsx` uses the unchanged path geometry of `Edit 24 Color`; `FluentToolbarIcon.tsx` uses the package's regular 24-pixel assets and the unchanged subpath geometry of `Highlight 24 Regular`:

https://github.com/microsoft/fluentui-system-icons/blob/main/assets/Edit/SVG/ic_fluent_edit_24_color.svg

https://github.com/microsoft/fluentui-system-icons/blob/main/assets/Highlight/SVG/ic_fluent_highlight_24_regular.svg

The selected tool color changes semantic fills or CSS masks only. No icon geometry is drawn or reshaped by Tafelraum.
